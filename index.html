Library

Every book listed here is reachable directly via the REST API.

For developers & AI agents

Everything in this library is served as a plain, read-only REST API — no key, no auth, JSON in, JSON out.

Base URL https://eduteach-textbook-api.onrender.com
GET/published/books

List every published book. Optional query params board, grade, subject, language filter the results.

GET/published/books/{book_id}/chapters

List one book's chapters — titles and page ranges.

GET/published/books/{book_id}/chapters/{chapter_number}

One chapter's full content: noise-free text with <img id="..."/> placeholders, plus every image resolved to a fetchable URL (or a caption-only entry when there's no file, tagged usage: "generate" or "draw").

Book IDs are deterministic

If you already know a school's board, grade, subject and language, you can build book_id directly and skip the list lookup:

{board}_class{grade}_{subject}_{language}

lowercased, spaces → underscores — e.g. ts_scert_class5_maths_en.
